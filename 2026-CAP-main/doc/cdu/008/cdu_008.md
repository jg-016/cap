# CDU-008 Consultar calendários - CASO REMOVIDO

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante consulta seus calendários.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: Nenhuma.

## Fluxo Principal

|                         Ações do ator                         |                    Ações do sistema                    |
| :--------------------------------------------------------------: | :------------------------------------------------------: |
|   1 - Estudante seleciona a opção "Consultar calendários".   | 2 - Sistema exibe a lista de calendários disponíveis. |
|             3 - Estudante visualiza os calendários.             | 4 - Sistema mantém a lista disponível para seleção. |
| 5 - Estudante escolhe um calendário para visualizar os eventos. | 6 - Sistema exibe os eventos do calendário selecionado. |

## Fluxo Alternativo I - Nenhum calendário disponível

|                               Ações do ator                               |                        Ações do sistema                        |
| :-------------------------------------------------------------------------: | :---------------------------------------------------------------: |
| 1.1 - Estudante acessa a consulta quando não há calendários cadastrados. | 1.2 - Sistema informa que não existem calendários disponíveis. |

## Fluxo Alternativo II - Calendário indisponível

|                             Ações do ator                             |                                 Ações do sistema                                 |
| :----------------------------------------------------------------------: | :--------------------------------------------------------------------------------: |
| 2.1 - Estudante tenta selecionar um calendário que está indisponível. | 2.2 - Sistema informa que o calendário não está disponível e retorna à lista. |
