# CDU-022 Remover calendário de turma

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante desassocia um calendário de uma turma.
- **Pré-condição**: O estudante está autenticado no sistema e é administrador da turma.
- **Pós-Condição**: O calendário é apagado.

## Fluxo Principal


| Ações do ator                                                | Ações do sistema                                                                            |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| 1. O estudante acessa a página da turma.                     | 2. O sistema exibe os calendários associados à turma.                                       |
| 3. O estudante seleciona a opção “Remover” de um calendário. | 4. O sistema apresenta uma mensagem de confirmação da remoção.                              |
| 5. O estudante confirma a remoção.                           | 6. O sistema recebe o identificador da turma e do calendário selecionado.                   |
|                                                              | 7. O sistema verifica se o estudante é membro da turma e possui permissão de administrador. |
|                                                              | 8. O sistema busca a turma informada.                                                       |
|                                                              | 9. O sistema busca o calendário associado à turma.                                          |
|                                                              | 10. O sistema remove a associação do calendário com a turma.                                |
|                                                              | 11. O sistema salva a alteração.                                                            |
|                                                              | 12. O sistema redireciona o estudante para a página da turma.                               |
|                                                              | 13. O sistema exibe a turma sem o calendário removido.                                      |


## Fluxo Alternativo I - Estudante sem permissão

| Ações do ator                                                                 | Ações do sistema                                                                                                       |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 1.1. O estudante tenta remover um calendário de uma turma que não administra. | 1.2. O sistema verifica a permissão do estudante e identifica que ele não possui autorização para realizar a operação. |
|                                                                               | 1.3. O sistema não remove o calendário e exibe uma mensagem de erro.                                                   |


## Fluxo Alternativo II - Dados incorretas

| Ações do ator                                                                            | Ações do sistema                                                                                             |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 2.1. O estudante tenta remover um calendário utilizando dados inválidos ou inexistentes. | 2.2. O sistema identifica que a turma ou o calendário não pode ser encontrado ou não está associado à turma. |
|                                                                                          | 2.3. O sistema não realiza a remoção e exibe uma mensagem de erro ao estudante.                              |
