# CDU-001 Entrar

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante acessa o sistema.
- **Pré-condição**: O estudante não está autenticado no sistema.
- **Pós-Condição**: O estudante está autenticado no sistema.

## Fluxo Principal

|                           Ações do ator                           |                   Ações do sistema                   |
| :------------------------------------------------------------------: | :----------------------------------------------------: |
|           1 - Estudante acessa o formulário de login.           | 2 - estudante preeche as credenciais de acesso (Email ou nome de usuário) e senha. |
| 3 - Sistema valida os dados  inseridos com base nas informações do banco de dados. |                          ....                          |
|            4 - sistema autentica o estudante          |        5 - sistema redireciona o estudante para a página principal.        |
|                                 ....                  |

## Fluxo Alternativo I - Dados inválidos

|                           Ações do ator                           |                          Ações do sistema                          |
| :------------------------------------------------------------------: | :------------------------------------------------------------------: |
| 1.1 - Envia formulário com dados inválidos ou senha incompatível. | 1.2 - Sistema exibe mensagem de erro indicando os campos inválidos. |
|           1.3 - Corrige os dados e reenvia o formulário.           |    1.4 - Sistema retoma a validação e segue o fluxo principal.    |
