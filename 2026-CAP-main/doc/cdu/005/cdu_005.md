# CDU-005 Atualizar conta

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante atualiza as informações de sua conta.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: Os dados da conta do estudante estão atualizados.

## Fluxo Principal

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|     1 - O estudante acessa a opção “Perfil”.     |      2 - O sistema exibe os dados atuais da conta.              |
|     3 - O estudante seleciona “Editar perfil”.           |      4 - O sistema disponibiliza os campos editáveis.      |
|     5 - O estudante altera o nome e/ou e-mail e seleciona “Salvar”.           |      6 - O sistema valida os dados informados.       
|         |      7 - O sistema atualiza os dados da conta.       |
|               |      8 - O sistema exibe o perfil atualizado e uma mensagem de sucesso.       |
