# CDU-005 Atualizar conta

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante atualiza as informações de sua conta.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: Os dados da conta do estudante estão atualizados.

## Fluxo Principal

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|     1 - O estudante acessa a opção “Perfil”.     |      2 - O sistema exibe os dados atuais da conta, incluindo nome, e-mail e data de cadastro.              |
|     3 - O estudante seleciona “Editar perfil”.           |      4 - O sistema disponibiliza o campo de nome para edição e exibe as opções “Alterar senha” e “Excluir conta”.      |
|     5 - O estudante altera os dados e seleciona “Salvar”.           |      6 - O sistema valida os dados informados.       
|         |      7 - O sistema atualiza os dados da conta.       |
|               |      8 - O sistema exibe o perfil atualizado e uma mensagem de sucesso.       |

## Fluxo Alternativo I - Dados Inválidos

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|    1.1 - O estudante deixa o campo de nome vazio e seleciona “Salvar”.    |                    |
|                |     1.2 - O sistema identifica que o campo obrigatório não foi preenchido.     |
|                |     1.3 - O sistema exibe uma mensagem informando que o nome é obrigatório e não realiza a atualização.     |

## Fluxo Alternativo II - Cancelar Edição

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|    2.1 - O estudante seleciona “Cancelar” durante a edição.    |                    |
|                |     2.2 - O sistema descarta as alterações não salvas e retorna à visualização do perfil.     |

> Obs. as seções a seguir apenas serão utilizadas na segunda unidade do PDSWeb (segundo orientações do gerente do projeto).
