# CDU-019 Atualizar turma

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante atualiza as informações de uma turma.
- **Pré-condição**: O estudante está autenticado no sistema e vinculado a uma turma, na qual é administrador. 
- **Pós-Condição**: Os dados da turma estão atualizados.

## Fluxo Principal


| Ator                                                                                     | Sistema                                                                               |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1. O estudante acessa a página da turma que administra.                                  | 2. O sistema exibe a página da turma com suas informações.                            |
| 3. O estudante visualiza o nome, código, administrador e demais informações da turma.    | 4. O sistema disponibiliza a opção **“Atualizar turma”**.                             |
| 5. O estudante seleciona a opção **“Atualizar turma”**.                                  | 6. O sistema abre o modal **“Atualizar turma”** sobre a página atual.                 |
|                                                                                          | 7. O sistema exibe o campo **“Nome da turma”** preenchido com o nome atual.           |
|                                                                                          | 8. O sistema exibe o campo **“Descrição”** preenchido com a descrição atual da turma. |
| 9. O estudante seleciona o campo **“Nome da turma”** e altera o nome, caso necessário.   |                                                                                       |
| 10. O estudante seleciona o campo **“Descrição”** e altera a descrição, caso necessário. |                                                                                       |
| 11. O estudante revisa os dados preenchidos no modal.                                    | 12. O sistema mantém os novos dados preenchidos nos campos do formulário.             |
| 13. O estudante seleciona o botão **“Salvar alterações”**.                               | 14. O sistema valida os dados informados.                                             |
|                                                                                          | 15. O sistema atualiza as informações da turma.                                       |
|                                                                                          | 16. O sistema salva as alterações realizadas.                                         |
|                                                                                          | 17. O sistema fecha o modal de atualização e retorna para à página da turma.          |
                                                                                          
## Fluxo Alternativo I - ...

| Ator                                       | Sistema                                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| 1. O estudante solicita a edição da turma. | 2. O sistema consulta se o estudante possui permissão de administrador da turma.                        |
|                                            | 3. O sistema identifica que o estudante não é administrador da turma.                                   |
|                                            | 4. O sistema retorna um erro de permissão.                                                              |
|                                            | 5. O sistema exibe uma mensagem informando que o estudante não possui permissão para atualizar a turma. |
|                                            | 6. O sistema não realiza a atualização.                                                                 |


## Fluxo Alternativo II - ...

| Ator                                       | Sistema                                                                    |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| 1. O estudante solicita a edição da turma. | 2. O sistema recebe o `turma_id`.                                          |
|                                            | 3. O sistema busca a turma pelo identificador informado.                   |
|                                            | 4. O sistema não encontra a turma.                                         |
|                                            | 5. O sistema retorna um erro.                                              |
|                                            | 6. O sistema exibe uma mensagem informando que a turma não foi encontrada. |
|                                            | 7. O sistema não realiza a atualização.                                    |
