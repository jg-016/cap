# CDU-010 Atualizar calendário

> Guia detalhado da implementação: [implementação do CDU-010](implementacao_cdu_010.md).

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante atualiza as informações de um calendário.
- **Pré-condição**: O estudante está autenticado no sistema e é administrador do calendário.
- **Pós-Condição**: Os dados do calendário estão atualizados.

## Fluxo Principal

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
| 1 - O estudante acessa um calendário do qual é administrador e seleciona a opção “Editar calendário”. | 2 - O sistema exibe o formulário de atualização com o nome e a descrição atuais do calendário. |
| 3 - O estudante altera o nome e/ou a descrição do calendário. | |
| 4 - O estudante envia o formulário. | 5 - O sistema valida os dados informados. |
| | 6 - O sistema atualiza os dados do calendário e confirma o sucesso da operação. |
| 7 - O estudante consulta o calendário atualizado. | 8 - O sistema exibe o calendário com os novos dados. |

## Fluxo Alternativo I - Dados inválidos

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
| 1.1 - O estudante envia o formulário com dados inválidos ou campos obrigatórios vazios. | 1.2 - O sistema informa os campos que precisam ser corrigidos e mantém os dados preenchidos. |
| 1.3 - O estudante corrige os dados e envia novamente o formulário. | 1.4 - O sistema valida os dados e retoma o fluxo principal a partir do passo 6. |

## Fluxo Alternativo II - Cancelar atualização

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
| 2.1 - O estudante cancela a atualização antes de enviar o formulário. | 2.2 - O sistema descarta as alterações não enviadas e retorna à visualização do calendário, mantendo os dados originais. |

## Fluxo Alternativo III - Estudante sem permissão

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
| 3.1 - Um estudante que não é administrador tenta acessar a opção ou enviar uma atualização do calendário. | 3.2 - O sistema nega a operação, informa que somente administradores podem atualizar o calendário e mantém os dados inalterados. |

> Obs. as seções a seguir apenas serão utilizadas na segunda unidade do PDSWeb (segundo orientações do gerente do projeto).
