# CDU-010 Atualizar calendário

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante atualiza as informações de um calendário.
- **Pré-condição**: O estudante está autenticado no sistema e é administrador do calendário.
- **Pós-Condição**: Os dados do calendário estão atualizados.
