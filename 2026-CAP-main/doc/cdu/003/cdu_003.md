# CDU-003 Criar conta

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante cria uma conta no sistema.
- **Pré-condição**: o estudante não tem conta registrada no sistema.
- **Pós-Condição**: A conta do estudante está registrada no sistema.

## Fluxo Principal

|                           Ações do ator                           |                   Ações do sistema                   |
| :------------------------------------------------------------------: | :----------------------------------------------------: |
|           1 - Estudante acessa o formulário de cadastro.           | 2 - Sistema exibe o formulário de criação de conta. |
| 3 - Estudante preenche nome, e-mail, senha e confirmação de senha. |                          ....                          |
|            4 - Estudante envia o formulário de cadastro.            |        5 - Sistema valida os dados informados.        |
|                                 ....                                 | 6 - Sistema cria a conta e exibe mensagem de sucesso. |

## Fluxo Alternativo I - Dados inválidos

|                           Ações do ator                           |                          Ações do sistema                          |
| :------------------------------------------------------------------: | :------------------------------------------------------------------: |
| 1.1 - Envia formulário com dados inválidos ou senha incompatível. | 1.2 - Sistema exibe mensagem de erro indicando os campos inválidos. |
|           1.3 - Corrige os dados e reenvia o formulário.           |    1.4 - Sistema retoma a validação e segue o fluxo principal.    |
