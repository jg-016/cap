# CDU-004 Visualizar conta

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante visualiza as informações de sua conta.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: Nenhuma.

## Fluxo Principal

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|     1 - O estudante acessa a opção “Perfil”.     |        2 - O sistema identifica o estudante autenticado.           |
|                |      3 - O sistema recupera os dados da conta.      |
|                |      4 - O sistema exibe a página de perfil com as informações do estudante.      |
