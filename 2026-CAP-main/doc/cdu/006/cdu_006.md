# CDU-006 Deletar conta

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante remove sua conta do sistema.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: A conta do estudante não está mais registrada no sistema.

## Fluxo Principal

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|     1 - O estudante acessa a opção “Perfil”.     |      2 - O sistema exibe os dados da conta.              |
|    3 -  O estudante seleciona “Excluir conta”.           |      4 - O sistema solicita a confirmação da exclusão.      |
|    5 -  O estudante confirma a exclusão.        |      6 - O sistema exclui a conta do estudante.      |
|         |      7 - O sistema encerra a sessão e redireciona para a página de login.      |

## Fluxo Alternativo I - Cancelar exclusão

| Ações do ator | Ações do sistema |
| :-------------: | :----------------: |
|    1.1 - O estudante seleciona “Cancelar”.    |    1.2 - 4.2. O sistema cancela a operação e mantém a conta ativa.                |
|                |        |
