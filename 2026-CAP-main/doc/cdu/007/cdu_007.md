# CDU-007 Criar calendário

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante cria um calendário.
- **Pré-condição**: O estudante está autenticado no sistema.
- **Pós-Condição**: O calendário está registrado no sistema.

## Fluxo Principal

|                     Ações do ator                     |                         Ações do sistema                         |
| :------------------------------------------------------: | :----------------------------------------------------------------: |
|   1 - Estudante acessa a opção de criar calendário.   |    2 - Sistema exibe o formulário de criação de calendário.    |
| 3 - Estudante informa nome e descrição do calendário. |                                                                    |
|            4 - Estudante envia o formulário.            |              5 - Sistema valida os dados informados.              |
|                           ...                           | 6 - Sistema cria o calendário e confirma o sucesso da operação. |

## Fluxo Alternativo I - Dados inválidos

|                        Ações do ator                        |                          Ações do sistema                          |
| :------------------------------------------------------------: | :------------------------------------------------------------------: |
| 1.1 - Estudante envia formulário com informações inválida. | 1.2 - Sistema exibe mensagem de erro indicando os campos inválidos. |
|   1.3 - Estudante corrige os dados e reenvia o formulário.   |           1.4 - Sistema valida e segue o fluxo principal.           |

> Obs. as seções a seguir apenas serão utilizadas na segunda unidade do PDSWeb (segundo orientações do gerente do projeto).
