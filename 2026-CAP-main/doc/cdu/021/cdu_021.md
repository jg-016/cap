# CDU-021 Adicionar calendário à turma

- **Ator principal**: Estudante
- **Atores secundários**: Nenhum
- **Descrição**: O estudante associa um calendário a uma turma.
- **Pré-condição**: O estudante está autenticado no sistema e é administrador da turma.
- **Pós-Condição**: O calendário está associado à turma.

## Fluxo Principal

| Ações do ator                                             | Ações do sistema                                                                            |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 1. O estudante acessa a página da turma.                  | 2. O sistema exibe as informações da turma e a opção de adicionar um calendário.            |
| 3. O estudante seleciona a opção de adicionar calendário. | 4. O sistema apresenta a tela de Criar Calendário.                          |
| 5. O estudante informa os dados do calendário (Nome, Descrição, etc.).                 | 6. O sistema recebe o identificador da turma.   |
|                                                           | 7. O sistema verifica se o estudante é membro da turma e possui permissão de administrador. |
|                                                           | 8. O sistema busca a turma informada.                                                       |
|                                                           | 9. O sistema cria o calendário com as informações dadas pelo estudante.                                                |
|                                                           | 10. O sistema associa o calendário à turma.                                                 |
|                                                           | 11. O sistema salva a associação.                                                           |
|                                                           | 12. O sistema redireciona o estudante para a página da turma.                               |
|                                                           | 13. O sistema exibe o calendário associado à turma.                                         |


## Fluxo Alternativo I - Estudante sem permissão


| Ações do ator                                                                  | Ações do sistema                                                                                                       |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 1.1. O estudante tenta adicionar um calendário a uma turma que não administra. | 1.2. O sistema verifica a permissão do estudante e identifica que ele não possui autorização para realizar a operação. |
|                                                                                | 1.3. O sistema não realiza a associação do calendário e exibe uma mensagem de erro.                                    |



## Fluxo Alternativo II - Dados incorretos

| Ações do ator                                                                              | Ações do sistema                                                                         |
| ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 2.1. O estudante tenta adicionar um calendário utilizando dados inválidos ou inexistentes. | 2.2. O sistema identifica que a turma ou o calendário informado não pode ser encontrado. |
|                                                                                            | 2.3. O sistema não realiza a associação e exibe uma mensagem de erro ao estudante.       |
