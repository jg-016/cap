# CAP - Calendário Acadêmico de Prazos

<img src="doc/design/logo-projeto/logo-principal-fundo.png" width="200" height="200" />

>Inserir pequena descrição do projeto

O Calendário Acadêmico de Prazos (CAP) é uma aplicação web voltada para estudantes, com a missão de:
- Centralizar as obrigações acadêmicas de uma turma em uma única interface de calendário
- Promover o protagonismo estudantil na organização de sua vida escolar, sem a necessidade de professores e instituições formais
- Criar espaços colaborativos para estudantes de uma mesma turma
- Conciliar o cumprimento dos deveres escolares e a vida pessoal do estudante
Para isso, permitimos que os estudantes gerenciem seus eventos e tarefas, tanto pessoais quanto vinculados a turmas!
